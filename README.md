## 1. Natural Outbreaks

### 1.1 Antonine Plague (Plague of Galen)

| Attribute | Details |
|---|---|
| **Start Year** | 165 CE |
| **End Year** | 180 CE |
| **Location** | Roman Empire (Italy, Egypt, Asia Minor) |
| **Cause** | Likely smallpox or measles, brought back by soldiers returning from the Near East |
| **Death Toll** | 7–10 million; 7–10% of the empire's population |
| **Economic Cost** | Triggered price and wage shocks; contributed to the Crisis of the Third Century |
| **Deployed Units** | No organized public health response; local temples and physicians |
| **How It Ended** | Natural immunity; population recovery over decades |
| **Why It Happened** | Military campaigns and trade routes (Silk Road) facilitated spread |
| **Key Insight** | Named after Galen, physician to Emperor Marcus Aurelius |

### 1.2 Plague of Cyprian

| Attribute | Details |
|---|---|
| **Start Year** | 250 CE |
| **End Year** | 270 CE |
| **Location** | Roman Empire, Mediterranean |
| **Cause** | Unknown; possibly a viral hemorrhagic fever (filovirus) or smallpox |

| **Economic Cost** | Sharp and permanent decline in economic activity; population decline, army reduction |
| **Deployed Units** | Early Christian charity networks provided care |
| **How It Ended** | Natural immunity; lasted over a decade |
| **Why It Happened** | Urban overcrowding, poor sanitation |
| **Key Insight** | Alexandria's population dropped from 500,000 to 190,000 |

### 1.3 Justinianic Plague (First Plague Pandemic)

| Attribute | Details |
|---|---|
| **Start Year** | 541 CE |
| **End Year** | 750 CE |
| **Location** | Mediterranean world, Europe, North Africa |
| **Cause** | *Yersinia pestis* bacterium |
| **Death Toll** | 25–50% of the Mediterranean population; tens of millions |
| **Economic Cost** | Major crisis in imperial finances; decline in tax revenues; inflationary pressures |
| **Deployed Units** | No organized response; Byzantine state focused on military recruitment |
| **How It Ended** | Endemic cycles; population adaptation |
| **Why It Happened** | Grain trade routes from Egypt; climate cooling (Late Antique Little Ice Age) |
| **Key Insight** | First recorded plague pandemic; recent scholarship debates its true demographic impact |

### 1.4 Black Death (Second Plague Pandemic)

| Attribute | Details |
|---|---|
| **Start Year** | 1347 |
| **End Year** | 1351 |
| **Location** | Eurasia (Europe, Asia, North Africa) |
| **Cause** | *Yersinia pestis*, spread by fleas on rats |
| **Death Toll** | 75–200 million; 30–50% of European population |
| **Economic Cost** | Global economic output fell by ~40%; wages and per capita income rose |
| **Deployed Units** | Quarantine measures (Venice's 40-day *quarantena*) |
| **How It Ended** | Natural immunity, reduced population density, quarantine |
| **Why It Happened** | Trade routes (Silk Road), overcrowded cities, poor sanitation |
| **Key Insight** | Wages rose for survivors; feudal system weakened |

### 1.5 Cocoliztli Epidemic

| Attribute | Details |
|---|---|
| **Start Year** | 1545 |
| **End Year** | 1548 |
| **Location** | Mexico (highlands of New Spain) |
| **Cause** | Likely *Salmonella enterica*; described as a hemorrhagic fever |

| **How It Ended** | Population collapse reduced transmission |
| **Why It Happened** | Zoonotic spillover; drought conditions; poor sanitation |

## 6. Key Patterns & Lessons

| Pattern | Observation |
|---|---|
| **Economic cost rises even as deaths fall** | Modern outbreaks kill fewer but cost more due to interconnected economies |
| **Zoonotic spillover dominates** | Most natural outbreaks originate from animal reservoirs |
| **Lab leaks are rare but consequential** | 1977 H1N1, 1979 Sverdlovsk, 1979 Birmingham |
| **Response speed determines outcome** | 2014 Ebola vs. 2024 Rwanda Marburg |
| **Vaccines change everything** | Smallpox eradication; COVID-19 vaccine development |
| **Preparedness ROI is 3:1** | Prevention costs $10–11.5B/year vs. $30B management |
| **Colonialism amplified outbreaks** | 1520 Smallpox, Cocoliztli, Third Plague Pandemic |
| **Climate plays a role** | Drought linked to Third Plague Pandemic; climate cooling to Justinianic Plague |
